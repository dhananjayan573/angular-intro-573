Router example

One URL, one screen.

Routes map a URL to a standalone component. This screen lives at /routing-example.

app.routes.ts

const routes: Routes = [
{{ '{' }} path: 'architecture', component: ArchitecturePageComponent {{ '}' }},
{{ '{' }} path: 'routing-example', component: RoutingExampleComponent {{ '}' }}
];

The router matches the URL and renders the selected component inside <router-outlet>.
